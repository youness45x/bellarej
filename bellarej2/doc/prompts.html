How to use it

  1. One prompt = one image. Copy, paste, generate.
  2. For a character, also attach its reference sheet you already made.
  3. Tick the box when you keep the result. Ticks are saved in this browser.

Keep the image only if

  • The background is plain grey, with nothing behind.
  • No text, labels or frame anywhere.
  • Nothing is cut off: wings, tail, hat, feet.
  • All views are the same size. If not, generate again.

What each picture is for

  • Game picture: cut out and used in the game.
  • Background: the far scenery behind the street.
  • Your earlier sheets stay the style reference.
